# VveezeGITHUB — Портфолио и учебные проекты

Репозиторий содержит личные разработки в сфере бэкенда и автоматизации, а также учебные материалы за 2 курс.

---

## Навигация по проекту

* **[Личные проекты](./Projects/ЛИЧНЫЕ/)** — Разработка ПО, алгоритмы автоторговли и финтех-модули
  * Стек: `C#` • `C++` • `SQL` • `Web`
* **[Учебные проекты](./Projects/)** — Лабораторные и практические работы по методическим указаниям
  * Дисциплины: `ОАП` (Основы алгоритмизации и программирования) • `БД` (Базы данных)
* **[Документы и отчеты](./Документы/)** — Теоретические материалы, конспекты и презентации
  * Дисциплины: `ААС` (Архитектура аппаратных средств) • `ЭВМ` • `Web`

---

## Технологический стек

* **Languages:** C#, C++, TypeScript, JavaScript
* **Databases:** SQL (Relational DB)
* **Frontend:** HTML5, CSS3
* **Окружение и автоматизация:** Git, GitSync, GitHub CLI, GitHub Desktop
