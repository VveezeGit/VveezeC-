# Vveeze-Sandbox

Личный полигон и сборник мини-проектов по разным направлениям разработки. Все проекты пишутся, тестируются и синхронизируются в кроссплатформенном режиме.

## Направления и технологии

* C# — ООП, прикладные консольные программы и логика.
* C++ — алгоритмы, структуры данных и работа со стандартной библиотекой.
* HTML / CSS / JS (В планах: TypeScript) — веб-интерфейсы, адаптивная верстка и интерактивные скрипты.
* SQL — проектирование баз данных, написание запросов и работа с таблицами.

## Окружение

* Мобильная разработка: C# IDE на Android + автоматизация через GitSync
* Десктопная разработка: ПК + стандартный Git / GitHub Desktop
